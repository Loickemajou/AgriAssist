# How the application works

The application starts with the user that has the ability to register based on the user schema in the models.py. 
So the user can input:

    email=Column(String, unique=True)
    username=Column(String, unique=True)
    first_name=Column(String)
    last_name=Column(String)
    hashed_password=Column(String)
    role=Column(String)
    language=Column(String, default='en')
    lat=Column(Float)
    lng=Column(Float)

    The aim is that, the user should be able to allow the localisation on the app, so that tha lat and lng can be captured. This is useful since it is provided to the ai for better diagnosis.

Once the user is authenticated, he or she can create a diagnois by uploading either a photo or a video, and can also add the descriptions that he or she  sees (either by typing or by voice).
This is then passed to the model which analysis the user input and give the results. also the confidence of the result is also given by the model.

Based on the diagnosis, the user can now begin a chat with the model in order to ask for further detail and morever seek for advice.



In the future, it will be good to add the community where expert and even non expert farmers can sign up in order to provide advices to user seeking for help. Morever add a page where there will be market for people to buy and sell.

# Running the backend
This is mostly for windows
- Create a virtual environment:
     '''
     python -m venv (name of the virtual environment)
     example python -m venv maching_leanring_env
     '''
- Activate the virtual environment by typing 
     '''
     venv\Scripts\Activate.ps1 (for powershell)
     venv\Scripts\activate.bat (for command prompt)
     '''
     It should be noted that "venv" stands for the name of your environment, so replace it with the appropriate name.

- install the requirements in the requirements.txt
    '''
    pip install -r requirements.txt
    '''

- Finally run uvicorn main:app --reload

it shoud be noted that all this should be done inside the api. Moreover you need to setup and appropriate goog_api_key, which can be gotten from 
https://aistudio.google.com/app/api-keys

Then create your .env file  and inside, paste
GEMINI_API_KEY='your api key'
